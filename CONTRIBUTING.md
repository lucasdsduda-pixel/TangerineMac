# Contributing

Contributions are welcome. Please keep changes focused and document macOS version requirements.

1. Open an issue for substantial features or behavior changes.
2. Build with a current Swift toolchain on macOS.
3. Test image conversions with representative PNG, JPEG, TIFF, and PDF inputs.
4. Never include personal files or sample images containing private information in commits.

This project is an early prototype. Please clearly label limitations and avoid describing unimplemented features as available.
